NETFIYAT OTO - STATIK SURUM

KURULUM:
1. index.html ve admin.html dosyalarini hosting panelindeki public_html / www / htdocs klasorune yukle.
2. Ana site: https://alanadiniz.com/
3. Yonetim: https://alanadiniz.com/admin.html
4. Demo yonetici girisi: berke / 1234

ONEMLI SINIRLAMA:
Bu paket sadece HTML/CSS/JavaScript ile calisan statik surumdur. Araç kayıtları localStorage içinde, yani sadece işlemi yaptığın tarayıcıda saklanır. Admin şifresi de tarayıcı kodundadır; gerçek güvenlik sağlamaz. Birden fazla ziyaretçinin aynı araç ve fiyat verilerini görmesi, gerçek bayi tekliflerini yayınlamak ve güvenli yönetici paneli için backend + veritabanı gerekir. Örnek fiyatlar gerçek bayi fiyatı değildir.
